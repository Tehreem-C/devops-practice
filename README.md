# DevOps Learning & Practice — Tehreem Mirza

Hands-on DevOps labs, tasks, and notes covering containerization, CI/CD, infrastructure automation, and cloud/networking fundamentals. Organized by topic below.

## Contents

- **docker/** — Docker installation notes, a 3-tier app built with Docker, and a working sample app (`dockerfile`, `index.js`, `package.json`).
- **ansible/** — Ansible playbooks/tasks, including combined AWS + Ansible provisioning exercises.
- **terraform/** — Terraform infrastructure-as-code tasks and notes.
- **jenkins-cicd/** — Jenkins installation, GitHub integration, and CI/CD pipeline tasks.
- **kubernetes-aws/** — Kubernetes installation and AWS + Kubernetes deployment tasks.
- **networking/** — Core networking concepts with examples.
- **jira/** — Jira-based task tracking exercises.
- **labs-and-misc/** — Lab assignments and additional coursework not tied to a single tool.

## About

These are coursework and self-practice materials built while learning DevOps fundamentals — no live deployment is attached since most of this work is infrastructure/config-based rather than a hosted app.
